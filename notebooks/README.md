# Research and Training Notebooks

This directory contains Jupyter notebooks used during exploratory research, experimental model fine-tuning, and data annotation:

- `Acc_NoAcc.ipynb`: Binary accident vs. non-accident classification experiments.
- `automated_dataset_annotation_and_evaluation_with_grounding_dino_and_sam.ipynb`: Automated zero-shot dataset pseudo-labeling with Grounding DINO and Segment Anything (SAM).
- `fire_detection.ipynb`: Secondary hazard detection prototype for vehicle fires.
- `People Detection.ipynb`: Pedestrian and casualty detection experimentation.
- `Traffic_Accident.ipynb`: Traffic incident analysis and spatio-temporal feature exploration.
- `train_yolov8_object_detection_on_custom_dataset_pynb.ipynb`: YOLO custom dataset training and hyperparameter tuning notebook.
- `yolov8_accident_detection.ipynb`: Early YOLOv8 baseline accident detection notebook.
